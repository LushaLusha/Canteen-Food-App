CanteenFoodApp - 食堂打饭软件

本项目是一款轻量化校园食堂打分互动网页应用，全程纯前端开发，无需服务器、无需数据库，所有数据本地持久保存，部署简单、开箱即用。软件支持手机窄屏、平板宽屏双模式切换，适配不同设备浏览使用，界面干净清爽，操作简单易懂。

软件集成完整校园食堂打分功能，支持手动账号登录、发布食堂菜品评价、图片链接展示、留言互动、用户等级成长、经验值升级以及违规内容举报自动屏蔽功能。

本项目最大特色是搭载全套真实可用语音识别功能，所有输入框均支持普通话语音转文字录入，解决不会打字、打字慢的问题，麦克风授权即可稳定使用，无空壳功能。

整体功能完整、运行稳定、兼容性强，专为校园食堂打分、菜品评价、师生互动场景设计，可直接部署使用，适合个人项目展示与校园轻应用使用。
